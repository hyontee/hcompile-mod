# bykranin — модульная версия

Исходный `bykranin.pwn` (163 935 строк, один файл) разложен на **188 файлов**.
Код не менялся, кроме 3 строк (см. ниже): порядок и содержимое строго те же, что в оригинале.

## Как подключить
1. Скопируй `gamemodes/bykranin.pwn` и папку `gamemodes/bykranin_src/` в свой проект, в папку `gamemodes/` (рядом с `../include/`).
2. Компилируй `bykranin.pwn` как обычно. Пути `#include "bykranin_src/..."` — от папки главного файла, так же как уже работают `../include/...`.

## Структура
```
gamemodes/
  bykranin.pwn              главный файл: pragma, библиотеки, список #include модулей
  bykranin_src/
    MODULES.md              карта: файл -> размер -> ключевые функции
    systems/                43 модуля, которые уже были вставлены маркерами BEGIN INLINED
                            (blackjack, family, auction, fuel, transportCompany ...)
    core/                   остальной код (122 тыс. строк) по темам:
      decl/                 макросы, enum, глобальные массивы
      callbacks/            OnGameModeInit, OnPlayerUpdate, OnDialogResponse ... (каждый большой колбэк — свой файл)
      network/              ipacket_252 (обработчик пакетов клиента, 6.3 тыс. строк)
      vehicle/ property/ inventory/ economy/ admin/ family/ jobs/ casino/
      account/ ui/ social/ combat/ world/ server/ data/
tools/verify_split.py       проверка целостности
```

## Что проверено
- Разворот всех `#include` даёт **ровно те же 163 935 строк**, что и оригинал. Отличаются только 3 строки:
  `static const X[] =` -> `new const X[] =` (`gVehicleComponentOffset`, `gVehicleComponentList`, `g_vehicle_model_name_map`).
- Причина: в Pawn `static` виден только внутри своего файла, а эти 3 массива используются из других модулей.
  Остальные `static` используются только внутри своих файлов (проверено по всем 188 файлам).
- Каждый файл синтаксически замкнут: скобки, `#if/#endif`, комментарии и строки сбалансированы, разрезы только между объявлениями верхнего уровня.
- Кодировка cp1251 сохранена побайтово.

## Что НЕ проверено
- **Компиляция.** В моей среде нет `pawncc`. Логика проверки построчная, но первый компил лучше прогнать и прислать вывод, если будут ошибки.
- Раскладка по папкам `core/*` сделана эвристикой (по именам функций). Порядок файлов важен (это порядок исходника), а названия можно менять свободно; тема файла указана в `MODULES.md`.
