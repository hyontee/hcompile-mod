IMPORTANT:
The visual left sidebar itself belongs to the client GUI (fragment 73). The server mode does not contain the GUI renderer/assets. This archive adds the data needed for a client that supports cn/ct/cp. If your current client ignores these fields, the sidebar must also be updated in the client/GUI 73 resources.

After changing modes.pwn, compile it to gamemodes/modes.amx before starting the server.
