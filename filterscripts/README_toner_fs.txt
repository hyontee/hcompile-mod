Файл: toner_fs.pwn

Что делает:
- /toner включает и выключает тонер
- сохраняет состояние в scriptfiles/toner_save.ini
- после рестарта сервера заново применяет тонер
- при спавне машины тоже пытается применить тонер

Как поставить:
1. Закинь toner_fs.pwn в папку filterscripts
2. Скомпилируй в toner_fs.amx
3. В server.cfg добавь:
   filterscripts toner_fs

Важно:
Если при компиляции будет ошибка на SetVehicleToner, значит эта функция не объявлена
в текущих инклудах filterscript-а. Тогда нужно либо:
- подключить тот же include, где она объявлена
- либо убрать строку forward SetVehicleToner(vehicleid, value);
  и использовать уже существующее объявление из твоего проекта

Ограничение:
Если твой мод создаёт личные машины с новыми vehicleid после выгрузки,
то сохранение по ID может не совпасть с той же машиной. Для полностью
идеального варианта нужно уже привязывать сохранение к БД или номеру машины.
